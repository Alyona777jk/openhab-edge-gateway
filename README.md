# Smart Home Edge Gateway (OpenHAB 4.x Local-First)

Автономний шлюз розумного будинку на базі **OpenHAB 4.x**, спроектований за принципами Edge Computing без використання хмарних сервісів, зовнішніх API та CDN.

## 1. Архітектура рішення (Edge vs Cloud)

| Критерій | Cloud-centric підхід | Реалізований Edge Gateway |
| :--- | :--- | :--- |
| **Затримка (Latency)** | 150–800 мс (залежить від WAN) | **< 15 мс** (локальна шина MQTT/IPC) |
| **Відмовостійкість** | Повна втрата автоматизації без інтернету | **100% автономність** (Offline-first) |
| **Трафік (Bandwidth)** | Постійна передача сирої телеметрії | Передача лише агрегованих звітів при відновленні зв'язку |
| **Приватність** | Дані сенсорів зберігаються на сторонніх серверах | Локальні БД (`MapDB` + `RRD4J`) на вузлі |

### Схема потоків даних
1. **Рівень сенсорів та актуаторів:** ESP32 / Zigbee пристрої спілкуються напряму з локальним брокером `Mosquitto (127.0.0.1:1883)`.
2. **Рівень Edge-обробки (OpenHAB Rule Engine):** Правила `edge_autonomous.rules` обробляють показники температури та CO2 з використанням алгоритму гістерезису на самому шлюзі.
3. **Рівень локального зберігання:** `MapDB` миттєво фіксує стани актуаторів для відновлення після збою живлення; `RRD4J` зберігає історичні ряди фіксованого розміру.
4. **Рівень представлення:** BasicUI (`edge_dashboard.sitemap`) віддає статику та графіки локально на порт `8080` без зовнішніх бібліотек.

## 2. Стратегія Offline Operations
* **Виявлення ізоляції:** Модуль `network:pingdevice` опитує локальний шлюз маршрутизації кожні 15 секунд.
* **Graceful Degradation:** При втраті зв'язку система переходить у стан `OFFLINE_AUTONOMOUS`. Всі правила клімат-контролю продовжують працювати без змін.
* **Локальна буферизація:** Критичні події перемикання реле під час офлайну фіксуються лічильником `Edge_Buffered_Events` та зберігаються в `MapDB`.
* **Online Recovery:** Після відновлення мережі правило `Monitor Network & Graceful Degradation` автоматично ініціює скидання буфера подій та переводить шлюз у режим `ONLINE_LOCAL_SYNC`.

## 3. Характеристики продуктивності (Edge Optimization)
* **Обмеження JVM:** Виділено `-Xms256m -Xmx512m`, що дозволяє запускати систему на одноплатних комп'ютерах (Raspberry Pi 3/4, Orange Pi).
* **Зменшення зносу Flash-пам'яті:** Використання кільцевого буфера `RRD4J` виключає фрагментацію та переповнення накопичувача при тривалому офлайні.
* **Оптимізація частоти опитування:** Гістерезис (`±0.5 °C` та `150 ppm CO2`) запобігає зайвим записам у БД та перемиканням реле.
